Signatures and a hash chain at the base event, so a stored record can prove it hasn't been altered and, when signed, tie back to its producer.

Open source

03

Where the standards work meets running code in someone else's tree.

OCSF audit sink for the Praxis policy engine

Built inside AI Identity, then upstreamed into Praxis, an open-source gateway project maintained by Red Hat and IBM engineers, as the reference plugin reference/plugins/ocsf-audit. Every policy ruling leaves as a signed, hash-chained OCSF record.

A follow-on demo pairs the sink with an independent append-only ledger that receipts each record, so an auditor can confirm what happened without trusting the gateway.

The platform

04

AI Identity — evidence for what AI agents were allowed to do, and did

Founded and built solo as a working proof of the evidence architecture: an agent gets an identity and a mandate before it acts, every action passes a policy check, and what happened is written to a record that a third party can verify later. ai-identity.co ↗ (opens in a new tab)

Per-agent API keys

Each agent acts under its own credential, not a shared service key, so every action attributes to a specific agent.

Deny-by-default policy gateway

Agents act only where policy allows. No policy, no action.

Mandates

Delegated authority set before an agent acts: signed conditions, validity windows, and spend ceilings the gateway enforces.

Tamper-evident audit chain

An HMAC-SHA256 hash chain for tamper evidence, plus DSSE-signed session attestations.

Signed Case Files

Evidence bundles with a signed manifest that anyone holding the public key set can verify offline.

Retention & legal holds

Retention policies and legal holds, with tombstone receipts when records are reaped.

OCSF in and out

Audit records are emitted as OCSF, and signed records from enforcement points it doesn't host can be ingested.

Compliance evidence exports

Machine-readable and PDF export profiles that map agent activity to framework evidence.

SOC 2EU AI ActNIST AI RMF
Framing, stated plainly: the platform produces the evidence compliance frameworks ask for; it does not certify anyone compliant. That judgment belongs to an auditor.
